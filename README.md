# Cricket Scoreboard

A cricket scoreboard web app built with Angular 14 and Angular Material.

## Features
- Select the two teams for a match
- Pick players for the batting team
- Toss and team components scaffolded for the next steps
- Step-by-step match setup using a Material stepper

## Tech Stack
- Angular 14
- Angular Material
- TypeScript, SCSS

## Getting Started
```bash
npm install
ng serve
```
Then open `http://localhost:4200/`.

## Running Tests
```bash
ng test
```
